# Imprenta Gipe - Fine Printing & Luxury Finishes 🏛️✨

Sitio web corporativo y comercial de alta conversión para **Imprenta Gipe**, taller de impresión profesional especializado en acabados de lujo, fidelidad cromática CMYK estricta y cotización dinámica inmediata.

---

## 🎨 Identidad Visual & Tecnologías Gráficas

- **Firma CMYK:** Cuadrícula de cuatricromía pura (Cian `#00E5FF`, Magenta `#FF007F`, Amarillo `#FFD700`, Negro `#111116`).
- **Canvas Interactivo CMYK:** Partículas reactivas al cursor del mouse con física de dispersión y mezcla óptica de tintas offset.
- **Showcase 3D de Acabados:** Simulación volumétrica con reflejo de luz para **Pan de Oro (Hot Stamping 24K)** y **Barniz UV 3D Alto Relieve**.
- **Calculadora Dinámica de Cotización:** Motor paramétrico con cálculo en tiempo real de sustratos, tintas, acabados, economía de escala e integración con WhatsApp Business.
- **Biblia de Preprensa:** Especificaciones técnicas de impresión (CMYK, 300 DPI, 3 mm de sangrado, curvas y fórmulas de Rich Black).
